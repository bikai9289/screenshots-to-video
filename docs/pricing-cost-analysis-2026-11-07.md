# 截图转视频成本与定价测算

核查日期：2026-11-07。本文是公开价格下的测算，不是账户实际账单；尚未取得用户的实际充值金额、积分和支付账户地区。未修改套餐、支付价格或已购权益。

## 代码与官方计费依据

- `src/core/ai/seeapi.ts` 固定使用 `seedance-2-fast`、`reference-to-video`、`seeapi`，720p、无音频、仅参考图片，无参考视频。
- [官方模型文档](https://www.seeapi.com/docs/seedance-2-fast/reference-to-video/)：720p、无参考视频为 34 credits/秒。这里的“no video”指没有输入参考视频，不是输出无音轨。不能套用有参考视频的 20 credits/秒价格。
- 5/10/15 秒分别消耗 170/340/510 credits。关闭音频在所查公开规则里没有独立折扣；尚未用账户价格接口或真实生成账单核实最终扣费。
- [SeeAPI 价格页](https://www.seeapi.com/pricing/)：用浏览器分别点击 Monthly、Pay Once、Yearly，核对套餐及比较表，避免将动画数字当成实际售价。
- 公布的美元换算不是所有用户统一的充值价格。每 credit 的采购价 = 实付金额 ÷ 得到的 credits。

## 单次模型成本

以下假定所购积分最终全部使用，不包含闲置资金、付款换汇、单独审核费、退款、拒付、客服、税费和固定运营成本。

| 供应商采购档位 | 实付 / credits   |  5 秒 | 10 秒 | 15 秒 |
| -------------- | ---------------- | ----: | ----: | ----: |
| Basic 月付     | $29 / 3,200      | $1.54 | $3.08 | $4.62 |
| Starter 年付   | $199 / 24,000    | $1.41 | $2.82 | $4.23 |
| Pro 年付       | $799 / 150,000   | $0.91 | $1.81 | $2.72 |
| Studio 年付    | $1,199 / 320,000 | $0.64 | $1.27 | $1.91 |
| Creator 一次性 | $299 / 30,000    | $1.69 | $3.39 | $5.08 |
| Studio 一次性  | $499 / 60,000    | $1.41 | $2.83 | $4.24 |
| Scale 一次性   | $1,999 / 400,000 | $0.85 | $1.70 | $2.55 |

不要为尚未验证的销量提前花 $1,199 买年付低价：$1.91 是积分充分消耗后的分摊成本，不代表只付 $1.91 就能生成。月付也存在 $29 的现金投入，未使用额度应算进经营现金流。

## 当前套餐的压力情景

保守采用 Creator 一次性采购价、套餐全部使用且全部选择 15 秒。支付手续费仅用 [Stripe 美国标准国内卡价格](https://stripe.com/pricing) 2.9% + $0.30 举例，用户实际费率可能不同，国际卡和换汇另计。

| 当前售价 | 次数 | 模型成本 | 示例支付费 | 扣两项后贡献余额 | 再预留模型成本 20% 后 |
| -------- | ---: | -------: | ---------: | ---------------: | --------------------: |
| $9.90    |    1 |    $5.08 |      $0.59 |            $4.23 |                 $3.21 |
| $19.90   |    3 |   $15.25 |      $0.88 |            $3.77 |                 $0.72 |
| $29.90   |    5 |   $25.42 |      $1.17 |            $3.32 |                -$1.77 |

20% 是人为压力测试假设，不是实测失败率。上述贡献余额不是净利润；若供应商采购更便宜，余额会上升。它说明不能在未知采购价下直接把 $9.90 改为三次任意时长。

计算式：模型成本 = 34 × 秒数 × 次数 × 每 credit 实际采购价。贡献余额 = 售价 - 支付手续费 - 模型成本 - 自行承担的补偿/重试成本。

供应商 [退款政策](https://www.seeapi.com/refund-policy/) 承诺系统错误且非用户输入原因造成的失败自动退 credits。成功出片但用户不满意，不在这项承诺内。不能假定所有失败、超时或重做均免费。用户自行新建成功任务会再次付费；主动赠送重做才额外侵蚀商家利润。

R2 标准存储公开单价为 $0.015/GB-month，且网络出口免费。[Cloudflare 官方价格](https://developers.cloudflare.com/r2/pricing/)。最大 20 MiB 输入只存一天，按比例的纯存储量级约 $0.00001，另有请求和计费取整；不是每次多收几美元的原因。Workers、D1、域名等固定费用仍要另计。

一次 knowledge_ask 和一次定向 knowledge_read，合计 16 积分。命中的相关资料是《syntx.ai 冷启动路径调查报告》（2026-05-19，作者字段：哥飞）。原文报道的是代币制、分档订阅与 affiliate 分销，不是按一条视频统一标价；未给出该站 API 采购价、利润倍数或截图视频的最佳售价。

只引用这个案例的商业模式，不转载其付费报告的内容或表格。用户本人可在 [原报告](https://new.web.cafe/topic/wco7lvv2b9) 阅读。当前 [SYNTX 官方 FAQ](https://syntx.ai/faq) 独立确认：生成按不同 token 成本扣除；额外 token 可充值；剩余 token 保留但使用要求有效订阅。不能把它的月费除以“最多生成视频数”，当成同款 Seedance/720p/15 秒的单条成本。

## 建议与落地边界

1. 先明确实际采购单价。当前先用公开档位给出区间，不以最低年付档冒充实际成本。
2. 降低付款门槛可以先试 $3.90 的 **5 秒付费入门**，不是 $3.90 任意时长。按上述高采购价，模型 $1.69 + 示例支付费 $0.41，剩 $1.79；再留 20% 模型成本缓冲，剩约 $1.45，仍未扣固定费用、获客、税费和客服。这是待验证报价，不是已修改的套餐，也不保证市场转化。
3. 长短视频应按不同额度扣除：5/10/15 秒分别 1/2/3 个额度。例如 $9.90 买 3 个额度，可做三次 5 秒，或一次 5 秒加一次 10 秒，或一次 15 秒。这样多了短片试错机会，最高模型成本与原来的单次 15 秒相同，但三次任务的请求和审核成本会略增。重试失败退款也要按额度一致处理。
4. 若希望所有时长都显著降价，需要先降采购或模型成本，再做同一组截图的质量对比。官方 [Seedance 2 Mini 参考视频文档](https://www.seeapi.com/docs/seedance-2-mini/reference-to-video/) 的 720p 图片输入是 20 credits/秒，较当前 34 低约 41%。这只是单价差异，没有实测证明能保持相同 UI 质量；未切换模型、未发起付费生成。
5. 固定问题是“是否有人愿意付钱得到可发布的结果”。需要记录首购转化、实际消耗、满意成片前的生成次数与补偿费用。没有足够合格访客时，不能从零订单推导一定是价格造成。
6. 后续如实施积分化或套餐变更，应保留已付款订单原权益。当前余额按商品 ID 查实时次数，直接改旧 ID 的次数会追溯影响历史订单；要用新商品 ID 或权益快照设计迁移，并按项目规则补齐金钱/权益与并发测试。
